# ALL-IN DEFENSE

`all-in-defense-final-game-plan.md` v2.2를 바탕으로 제작한 React + TypeScript + PixiJS 디펜스 게임입니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`, 게임 규칙 검증은 `npm test`로 실행합니다.

## 핵심 게임 루프

- 상점에서 유닛을 구입해 아군 구역에 배치하고, 클릭 또는 드래그로 단일·다중 선택합니다.
- 적 500명이 여러 그룹으로 진입하며 그룹 사이에는 다음 공세를 준비할 5초가 주어집니다.
- 적은 시작점에서 한 명씩 끊김 없이 진입하며 병종별 색상으로 빠르게 구분할 수 있습니다.
- 홈 화면의 `MAP BUILD`에서 건물 8종, 지형 8종, 바닥 재질 8종을 배치하고 적 이동 경로를 직접 그릴 수 있습니다.
- `MAP BUILD`는 정사각형 탑다운 GRID로 표시되어 타일 경계와 배치 칸을 바로 확인할 수 있으며, 전투에서는 기존 아이소메트릭 시점으로 돌아갑니다.
- 맵 크기를 최대 200×160 GRID까지 변경하고, 카메라 배율을 유지한 채 선택한 바닥 재질로 빈틈없이 전체 채우거나 드래그로 칠할 수 있습니다.
- 여러 소환 지점과 게이트를 가진 복수 경로를 만들 수 있으며 적은 각 경로에서 3열 대형으로 이동합니다.
- 전장 에셋과 이동 경로는 브라우저에 자동 저장되며 다음 플레이부터 바로 적용됩니다.
- 40/140/280/430킬마다 전리품 기회가 열립니다. 안전 회수하거나 Big Six에 걸어 더 큰 보상을 노릴 수 있습니다.
- 동일 병종·등급 유닛을 합성하고, 필요하면 판매하거나 대형을 다시 배치할 수 있습니다.
- 마지막 보스를 쓰러뜨리면 즉시 승리하며 전투 등급과 상세 통계가 표시됩니다.

## 조작

- 홈 화면 `MAP BUILD`: 맵 에디터 진입
- 건물·지형·바닥 이미지 선택 후 클릭 또는 드래그: GRID 스냅 연속 배치
- GRID 한 칸에는 바닥 재질 1개와 건물·지형 에셋 1개만 배치되며, 바닥 재질을 다시 칠하면 기존 재질을 교체합니다.
- 드래그 편집은 변경된 타일만 렌더링하고 마우스를 놓을 때 한 번 저장하도록 최적화되어 있습니다.
- `바닥 재질` → `전체 채우기`: 선택한 재질로 맵 전체 도포
- `경로` → `새 시작·도착 경로`: 복수 소환 지점과 게이트 입력
- 상점 카드 선택 후 아군 배치 구역 클릭: 유닛 구입 및 배치
- 유닛 클릭: 단일 선택
- 빈 공간 드래그: 범위 다중 선택
- 선택한 뒤 빈 공간 클릭: 한 유닛 또는 대형 이동
- 같은 병종·등급 유닛끼리 드래그: 합성
- 우클릭 드래그 또는 `Shift + 드래그`: 카메라 이동

## 구현 범위

- 6종 아군, 5종 적, T1~T4 합성 및 병종별 공격 규칙
- 500명 연속 공세, 엘리트와 최종 보스
- 킬 마일스톤 전리품, 안전 회수, 보호 베팅 및 실제 54칸 Big Six 확률
- 고배당 적중 시 발동하는 15초 오버드라이브
- 탄환·폭발·빙결·감전·처치·보상 시각 효과와 절차적 전투 사운드
- 튜토리얼 힌트, 피해량 표시, 승패 결과 등급 및 런 통계
- ImageGen 기반 유닛·적·환경·건설물·지형 스프라이트와 PixiJS 폴백 캐릭터
- 데스크톱과 모바일 가로 화면용 반응형 HUD

이미지 생성 출처와 프롬프트 요약은 [`docs/asset-sources.md`](docs/asset-sources.md)에 기록되어 있습니다.
