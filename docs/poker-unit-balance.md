# 포커 족보·유닛 매칭 계획

## 핵심 원칙

- 포커 족보는 유닛 TIER가 아니라 **획득 병종**을 결정한다.
- 포커로 획득하는 모든 유닛은 T1이다.
- T2~T4는 같은 병종·같은 TIER 유닛 두 기를 합성할 때만 올라간다.
- 10개 족보에 맞춰 기본 병종도 10종으로 구성한다.
- 같은 족보가 여러 기를 지급하더라도 모두 동일한 병종의 T1 유닛이다.

## 문양의 역할

문양은 병종을 바꾸지 않는다. 현재는 보상 카드에 주 문양을 표시해 결과의 정체성을 유지한다. 추후 문양 패시브를 추가한다면 ♠ 사거리, ♥ 제어, ♦ 공격 속도, ♣ 범위 효과처럼 병종과 독립된 보조 특성으로 확장한다.

## 합성

- 동일 병종 T1 두 기 → T2 한 기
- 동일 병종 T2 두 기 → T3 한 기
- 동일 병종 T3 두 기 → T4 한 기
- 공통 피해 배율은 T1 `1.0`, T2 `2.2`, T3 `4.8`, T4 `10.5`다.
- 합성 후 한 기의 공격력은 합성 전 두 기의 총공격력보다 항상 높다.
- 실제 원본 수치와 계산 함수는 `src/game/data.ts`의 `UNITS`, `TIER_DAMAGE_MULTIPLIERS`, `getUnitDamage`다.
