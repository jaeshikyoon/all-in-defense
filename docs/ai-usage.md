# ALL-IN DEFENSE AI 활용 기술 문서

## 1. 문서 목적

이 문서는 ALL-IN DEFENSE 제작 과정에서 AI 도구를 어떤 역할에 사용했는지, 생성 결과를 어떻게 검토하고 실제 게임 코드에 반영했는지 정리한 기록입니다. AI는 기획 아이디어와 시각 에셋의 초안 생성에 활용했으며, 게임 규칙·구현·테스트·수정은 저장소 기준으로 검증했습니다.

## 2. 사용한 AI 도구

### OpenAI Codex / GPT

- React·TypeScript·PixiJS 구조 분석
- 전투 엔진과 포커 보상 루프 구현 보조
- 모바일 UI/UX 개선안과 접근성 문구 제안
- 버그 원인 분석 및 회귀 테스트 작성
- 성능·배속·그리드 스냅·맵 에디터 규칙 검토

### OpenAI ImageGen

- 아군 유닛과 적 유닛의 캐릭터 시트 제작
- 건물·지형·바닥 재질·전장 장식 에셋 제작
- 메인 메뉴 배경, 로고, UI 프레임, 경로 입구·출구 에셋 제작

## 3. 대표 프롬프트 방향

정확한 프롬프트의 핵심 조건은 다음과 같이 구성했습니다.

### 캐릭터 에셋

> 귀엽고 둥근 비율의 군사 SF 타워 디펜스 캐릭터, 명확한 실루엣, 강한 외곽선, 투명 배경, 동일한 카메라와 조명, 병종별 무기와 색상 차이, 게임 스프라이트 시트용 정면 3/4 포즈

### 건물·지형 에셋

> 아이소메트릭 군사 기지용 건물과 지형 오브젝트, 청록색 조명과 어두운 금속 재질, 반복 배치 가능한 투명 배경, 일정한 시점과 그림자, 그리드 풋프린트를 쉽게 식별할 수 있는 형태

### 배경·UI 에셋

> 방어 기지와 적 세력이 양쪽에 배치된 어두운 군사 SF 전장, 중앙에 UI가 들어갈 여백, 청록색 아군 조명과 주황색 적 조명, 가로형 게임 로고와 9-slice 확장 가능한 프레임

## 4. 에셋 제작 파이프라인

1. AI로 원본 시트와 방향성 후보를 생성했습니다.
2. 프로젝트의 둥글고 귀여운 캐릭터 스타일과 군사 SF 팔레트에 맞지 않는 결과를 제외했습니다.
3. 마젠타 크로마 배경을 제거하고 Pillow 기반 스크립트로 투명 PNG를 만들었습니다.
4. 캐릭터·건물·지형·바닥 타일을 동일한 런타임 크기로 정규화했습니다.
5. 바닥 타일은 인접 셀 사이에 틈이 생기지 않도록 2:1 아이소메트릭 규격으로 맞췄습니다.
6. 최종 에셋을 PixiJS 레이어와 실제 그리드 풋프린트에 연결했습니다.

세부 출처와 파일 매핑은 [`asset-sources.md`](./asset-sources.md)에 기록되어 있습니다.

## 5. 코드 구현에 AI를 활용한 영역

- 32장 포커 덱과 족보 판정
- 족보별 유닛 보상 매핑과 T1~T4 합성 배율
- 적 투입 스케줄과 PHASE 진행 규칙
- 다중 입구·공통 출구·3레인 경로 이동
- 그리드 셀 중앙 스냅과 다중 셀 건물 풋프린트
- 바닥·건물·지형 레이어 분리 및 에셋 교체 규칙
- IndexedDB 기반 맵 저장과 맵별 로컬 랭킹
- 1×/2×/4× 배속의 고정 시뮬레이션 틱
- 모바일 가로 화면, 드래그 선택, 줌, 일시정지, 사운드 UI

## 6. 검증과 사람의 판단

AI가 제안한 코드를 그대로 사용하지 않고 다음 절차를 반복했습니다.

- 실제 저장소의 참조 관계와 타입을 확인
- 실패한 플레이 상황을 재현하는 테스트 작성
- `npm test`로 포커·전투·저장·오디오·맵 경계·UI 규칙 검증
- `npm run build`로 TypeScript와 Vite 프로덕션 빌드 검증
- `git diff --check`로 패치 오류 확인
- 모바일 화면에서 버튼 겹침, 카드 배치, 맵 빌더 조작을 반복 점검
- 실제 플레이에서 발생한 순간이동, 배속 차이, 에셋 겹침, 경로 스냅 문제를 수정

최종 결과는 AI 생성물의 자동 산출물이 아니라, 기획 요구사항과 플레이 테스트를 기준으로 사람이 선택·수정·검증한 통합 결과입니다.

## 7. AI 활용의 한계와 향후 계획

- 현재 랭킹과 맵 공유는 로컬 IndexedDB만 사용합니다.
- AI가 생성한 이미지에는 추가적인 스타일 통일과 크기 보정이 필요했습니다.
- 실제 사용자 플레이 데이터가 축적되면 난이도와 포커 보상 밸런스를 다시 조정할 예정입니다.
- 향후 Firebase 기반 맵 공유·온라인 랭킹과 에셋 CDN을 연동할 수 있습니다.
