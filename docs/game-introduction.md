# ALL-IN DEFENSE 게임 소개 및 설명

## 1. 게임 개요

ALL-IN DEFENSE는 포커의 확률과 선택을 실시간 디펜스의 배치 판단으로 연결한 웹 게임입니다. 플레이어는 전투 전에 5장의 카드를 받고 일부 카드를 교체해 족보를 완성합니다. 족보에 따라 서로 다른 역할의 유닛을 얻고, 해당 유닛을 전장에 배치해 계속해서 강해지는 적의 행렬을 막습니다.

게임의 목표는 특정 스테이지를 클리어하는 것이 아니라, 게이트가 무너지기 전까지 최대한 많은 적을 처치하고 자신의 기록을 갱신하는 것입니다.

## 2. 핵심 재미

- 원하는 족보가 완성될지 기다리는 포커의 기대감
- 좋은 패가 강력한 유닛으로 변환되는 즉각적인 보상
- 부족한 패를 배치·합성·이동으로 복구하는 전술적 판단
- 이전 PHASE의 생존 적이 남아 다음 전투를 압박하는 누적 위기
- 높은 족보를 얻었을 때 위기를 역전하는 성장 경험

## 3. 게임 진행

### 포커 드로우

덱은 7~A의 8개 랭크와 4개 문양으로 구성된 32장입니다. 처음 5장을 받은 뒤 최대 3장의 카드를 교체할 수 있습니다. 최종 족보와 우세 문양에 따라 병종과 보상 수량이 정해집니다.

### 유닛 획득과 배치

보상 유닛은 기본적으로 T1으로 지급됩니다. 전장에 배치한 뒤 같은 병종과 티어의 유닛을 합성하면 T2~T4로 강화할 수 있습니다. 잘못된 배치 위치를 눌러도 보상 유닛은 소모되지 않으며, 유효한 셀을 다시 선택할 수 있습니다.

### PHASE 전투

각 PHASE는 정해진 적 조합을 일정한 간격과 휴식 패턴으로 투입합니다. 투입이 종료되면 모든 적이 제거되지 않았더라도 다음 포커 단계로 이동합니다. 남은 적은 전장에 계속 존재하므로, 좋지 않은 포커 결과가 실제 위기로 연결됩니다.

적은 공격하지 않고 설정된 경로를 따라 이동합니다. 여러 입구가 하나의 경로로 합류할 수 있고, 한 경로에는 세 개의 이동 레인이 적용됩니다.

## 4. 유닛 역할

| 족보 | 병종 | 역할 |
| --- | --- | --- |
| 하이 카드 | 예비군 | 최소 방어 전력 |
| 원 페어 | 소총병 | 낮은 체력 적 안정 처리 |
| 투 페어 | 기관총병 | 보병·돌격병 빠른 처리 |
| 트리플 | 빙결술사 | 범위 감속과 군중 통제 |
| 스트레이트 | 저격수 | 강적 대상 고위력 처형 |
| 플러시 | 폭파병 | 밀집 적 광역 피해 |
| 풀 하우스 | 박격포 | 넓은 장거리 광역 공격 |
| 포카드 | 테슬라 기사 | 여러 적 연쇄 공격 |
| 스트레이트 플러시 | 레일건 | 정예·저거너트 대상 초고위력 |
| 로열 플러시 | 대재앙포 | 후반 경량 적 소탕 |

## 5. 조작법

- 클릭: 유닛 선택 또는 배치
- 클릭 후 드래그: 다중 선택 및 맵 빌더 연속 배치
- 우클릭 또는 Shift 드래그: 카메라 이동
- 휠·핀치: 줌 인·아웃
- 1×/2×/4×: 전투 배속 변경
- 일시정지: 전투 시뮬레이션 정지 및 재개

## 6. MAP BUILDER

맵 빌더에서는 맵 크기, 바닥 재질, 지형, 방어 시설, 적 이동 경로를 편집할 수 있습니다. 경로의 각 점은 그리드 셀 중앙으로 스냅되며, 다중 입구와 공통 출구를 구성할 수 있습니다.

건물과 지형은 바닥 재질 위에 배치할 수 있습니다. 같은 셀의 건물·지형을 다시 클릭하면 새 에셋으로 교체되고, 바닥 재질도 같은 셀 안에서 독립적으로 교체됩니다. 맵은 JSON으로 저장·불러오기·복제할 수 있습니다.

## 8. 저장 및 랭킹

서버 없이 IndexedDB를 사용해 맵, 현재 선택 맵, 맵별 랭킹을 브라우저에 저장합니다. 랭킹 기준은 해당 맵·리비전에서의 적 처치 수이며, Firebase 연동을 위한 저장 모델을 고려한 구조로 작성되어 있습니다.

## 9. 현재 범위

현재 버전은 실시간 멀티플레이를 포함하지 않는 싱글 플레이 빌드입니다. 맵 공유와 온라인 랭킹은 향후 Firebase 계열 서비스로 확장할 수 있도록 JSON 맵 구조와 맵 ID·리비전 기반 기록 구조를 사용합니다.
