# 족보별 유닛 전투 역할 밸런스

실제 게임의 공격력 원본은 `src/game/data.ts`의 `UNITS`이며, TIER 공격력은 같은 파일의 `TIER_DAMAGE_MULTIPLIERS`와 `getUnitDamage`에서 계산한다. 이 문서는 해당 설정의 검토용 스냅샷이다.

## 공통 합성 배율

| TIER |  배율 | 직전 TIER 두 기 대비 |
| ---- | ----: | -------------------: |
| T1   |  ×1.0 |                    - |
| T2   |  ×2.2 |               +10.0% |
| T3   |  ×4.8 |             약 +9.1% |
| T4   | ×10.5 |             약 +9.4% |

합성 후 한 기의 발당 공격력은 합성 전 두 기의 발당 공격력 합보다 항상 높다. 합성의 대가는 공격력 손실이 아니라 배치 지점·공격 가능 구역·목표 분산 능력 감소와 오버킬이다.

## 족보별 T1 전투 역할

| 족보              | 병종·지급 수    | T1 피해 | 공격/초 | 핵심 역할                      |
| ----------------- | --------------- | ------: | ------: | ------------------------------ |
| 하이 카드         | 예비군 1기      |      12 |    1.05 | 최소 방어 전력                 |
| 원 페어           | 소총병 1기      |      20 |    1.25 | 체력이 낮은 적 마무리          |
| 투 페어           | 기관총병 2기    |       8 |    4.00 | 보병·돌격병 빠른 처리          |
| 트리플            | 빙결술사 1기    |      18 |    1.00 | 유령 척후병과 적 무리 감속     |
| 스트레이트        | 저격수 1기      |     460 |   0.364 | 일반 적과 정예 적 처형         |
| 플러시            | 폭파병 2기      |      40 |    0.55 | 밀집한 적 무리 제거            |
| 풀 하우스         | 박격포 2기      |      75 |    0.42 | 넓고 강한 장거리 광역 공격     |
| 포 카드           | 테슬라 기사 3기 |      60 |    0.90 | 분산된 적에게 강력한 연쇄 공격 |
| 스트레이트 플러시 | 레일건 3기      |   1,500 |    0.07 | 저거너트·지휘관 초고위력 공격  |
| 로열 플러시       | 대재앙포 4기    |     200 |    0.38 | 후반 경량 적 무리 제거         |

사거리, 광역 반경, 빙결 주변 피해, 테슬라 연쇄 비율은 유지한다. 저격수는 초당 0.364발로 직전 설정보다 2배 빠르게 공격하며, 빙결술사는 적의 이동속도를 50% 낮춘다. 저격수와 레일건은 정예병·저거너트·지휘관에게 `×2.0` 피해를 준다.

전체 적의 월드 이동속도에는 공통 `×0.2304` 보정을 적용한다. 기존 `×0.4608` 상태에서 이동속도를 절반으로 낮춘 값으로, 최초 기준보다 약 77% 느리다. 병종별 상대 속도와 경로 길이에 따른 거리 기반 이동 규칙은 유지하며, 빙결 중에는 보정된 현재 속도의 50%로 이동한다.

## PHASE 30 처치 기준

적 HP와 성장식은 변경하지 않았다.

- 저격수 T1: 460 피해로 유령 척후병 448 HP를 한 발에 처치한다.
- 레일건 T1 3기: 강적 일제 피해는 `1,500 × 2 × 3 = 9,000`이다. 저거너트 5,478 HP를 처치하며 지휘관 34,860 HP의 약 25.8%를 깎는다.
- 대재앙포 T1: 200 피해로 보병 199 HP를 한 발에 처치한다.
- 테슬라 3기의 4명 최대 연쇄 DPS는 `437.4`, 박격포 2기의 4명 광역 DPS는 `252`다.
